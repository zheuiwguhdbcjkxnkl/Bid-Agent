# 02 数据来源调研：中国招投标公开数据渠道全景、可得性与合规边界

> 项目背景：智能投标助手（多智能体：招标文件解析/废标条款识别/资质提取/标书撰写）+ 招投标知识问答 RAG（招标公告/招标文件问答）
> 调研日期：2026-08-17 ｜ 调研人：子代理（数据来源专项）
> 方法说明：本机 curl 直接访问各官方平台首页/列表页/详情页实测核验（非二手转述）；海外云浏览器被国内政务网站 WAF 拦截（IP 问题），故全部采用本机直连核验。凡未能实测验证的条目一律标注 `[待核验]`。

## 0. 一页速览（TL;DR）

| 问题 | 结论 |
|---|---|
| 招标公告全文是否公开？ | **是**。四大国家级平台（CCGP/GGZY/CEBP/PLAP）公告正文均公开可读，无需登录 |
| 招标文件**全文**是否公开？ | **部分公开，取决于省份与项目类型**。三类情形：①附件直链公开下载（部分省份政府采购，**江苏已实测**：156KB .doc 免登录直下）；②注册供应商账号后免费下载（多数政府采购项目）；③需 CA 证书/第三方交易平台/付费获取（工程建设、央企、部分省份） |
| 中标公告含哪些字段？ | 项目名称、中标（成交）供应商、中标金额、主要标的信息、评审专家名单、代理机构、公告日期等（CCGP 结构化字段完整，已实测） |
| 历史数据能否回填？ | 能。CCGP 详情页按 `栏目/年月` 归档可回查多年；GGZY 有 `/history/dealList.html` 历史库入口；但新版列表页为 JS 分页、检索系统有反爬，**批量历史回填需逆向接口+控频** |
| 个人开发者合规主流做法？ | 公告类政府公开信息爬取用于学习/简历项目属低风险；遵守 robots（**CEBP 明确 `Disallow: /` 禁止爬取**）、控频、注明来源；商业再分发属灰色地带 |
| 推荐主选数据源 | **CCGP（政府采购）+ GGZY（工程建设）双主源**；备用 CEBP（公告类型全）、省级平台（江苏苏采云等，附件直链利于全文语料） |
| 最大风险 | CEBP robots 禁爬（合规）、CCGP 检索系统反爬（技术）、军队采购数据敏感（勿用于演示） |

## 2. 各渠道详细档案（重点渠道）

### 2.1 中国政府采购网（CCGP）—— 政府采购绝对主源 ✅ 推荐主选

- **栏目结构（已实测）**：中央公告 `/cggg/zygg/` 与地方公告 `/cggg/dfgg/` 下各有 11 个子栏目：`gkzb`(公开招标公告)、`yqzbgg`(邀请招标公告)、`jzxcs`(竞争性磋商)、`jzxtpgg`(竞争性谈判)、`xjgg`(询价)、`dylygg`(单一来源)、`zgysgg`(资格预审)、`zbgg`(中标公告)、`cjgg`(成交公告)、`gzgg`(更正公告)、`fblbgg`(废标流标公告)。
- **详情页 URL 模式**：`/cggg/{zygg|dfgg}/{栏目}/{YYYYMM}/t{YYYYMMDD}_{id}.htm` —— 按年月归档，**天然支持历史回填**。
- **公告字段（已实测，结构化程度高）**：项目名称、项目编号、公告时间、预算金额（精确到万元）、获取招标文件时间/地点/方式、招标文件售价、开标时间、投标截止时间、项目联系人/联系电话/代理机构。部分字段带 `data-tag-id` 结构化标注（官方已做数据化改造，对解析是利好）。
- **招标文件获取（已实测两类）**：
  - 江苏项目：公告内嵌附件直链 `ccgp-jiangsu.gov.cn/fileApi/.../xxx.doc`，**实测免登录直接下载成功（156KB Word）**；
  - 广西项目：无附件直链，写明"登录广西交投宏冠电子招标投标交易平台获取招标文件"（需第三方平台注册/CA）。
- **反爬（已实测）**：默认 curl UA 直接 403；带浏览器 UA 访问首页/列表/详情均 200。检索系统 search.ccgp.gov.cn 一次请求即被"频繁访问"拦截——**检索接口反爬强，批量检索必须控频**。
- 网站版权声明：1999-2024 财政部版权所有；未发现独立 robots.txt（403 响应）。

### 2.2 全国公共资源交易平台（GGZY）—— 工程建设主源 ✅ 推荐主选

- **定位**：国家发改委主管的全国性整合平台，汇聚各省级公共资源交易平台上报数据（实测详情页注明"信息来源：天津市公共资源交易平台交易系统"等）。
- **数据内容（已实测）**：单项目多 tab——招标/资审公告（0101）、开标记录（0102）、交易结果公示（0104）、招标/资审文件澄清（0105）。**正文页 `/information/deal/html/b/{区域}/{类型}/{日期}/{id}.html` 静态可抓**（实测 14.7KB 完整公告正文）。
- **列表为 JS 渲染**：页面内 `searchJson` 配置 + AJAX 接口 `/information/pubTradingInfo/getTradList`（实测 POST 404，参数需逆向[待核验]）。
- **历史库**：`/history/dealList.html` 独立历史检索入口（实测 200，同样 JS 渲染）。
- 无 robots.txt（404）。

### 2.3 中国招标投标公共服务平台（CEBP）—— 类型最全，但合规红线 ⚠️

- 公告类型全：招标公告、**中标候选人公示**、中标结果公示、资格预审公告、更正公告（实测首页栏目确认）。
- **数据规范公开**：`bulletin.cebpubservice.com/standard.html` 公开提供《招标公告和公示数据接口规范（试行）》下载（bulletin-info.rar，279KB，实测下载成功）——**这是理解公告数据字段结构的官方参考文档，强烈建议下载研读**（RAR 需解压工具，本机未解压[待核验内容]）。
- **合规红线：robots.txt = `User-agent: * / Disallow: /`**（实测获取）——明文禁止爬取。个人项目建议：仅作人工检索/参考规范用，不做批量爬取；或低频、注明来源。
- 附属 `ctbpsp.com` 搜索引擎可人工检索。

### 2.4 军队采购网（PLAP）—— 数据敏感，仅作背景了解

- 首页/栏目可访问（实测首页 267KB、采购公告列表页 200），公告类型含单一来源公示/询价/竞争性谈判/竞争性磋商等。
- 参与采购须注册军队供应商库（严格资质审查）；公告浏览门槛[待核验]。
- **不建议作为简历项目的数据源**：数据敏感性高，演示时易引起不必要的合规质疑。

### 2.5 省级平台 —— 全文语料的隐藏金矿

- 已验证：江苏（苏采云体系）公告附件直链公开可下载；广东公共资源交易平台可访问。
- 浙江、北京直连超时（网络环境问题，不代表不可用）[待核验]。
- **各省差异是"招标文件全文可得性"的关键变量**（见第 3 节）。

### 2.6 第三方聚合平台 —— 商业便利 vs 合规边界

- 剑鱼标讯/千里马/采招网/比地招标实测可访问；中国招标网有反爬（521）。
- 免费层级通常只能看标题摘要，全文/订阅/API 需付费。
- 优点：检索体验好、历史数据全、有 API；缺点：付费、条款限制再分发、数据溯源不清。

## 3. 关键问题专项：招标文件**全文**是否公开可得？

> 这是决定两个项目（尤其 RAG 全文语料）能否落地的核心问题。**实测结论：公告全文 100% 公开可得；招标文件全文分三类，需按省/项目类型分别对待。**

### 3.1 三类可得性（按获取难度排序）

| 类型 | 代表场景 | 获取方式 | 实测证据 | RAG 可用性 |
|---|---|---|---|---|
| **A. 附件直链公开** | 部分省份政府采购（江苏苏采云体系实测；浙江政采云等类似） | 公告页附件链接直接下载，免登录 | 江苏 .doc 直链 156KB 下载成功 | ⭐⭐⭐ 直接可用（PDF/Word 解析即可入库） |
| **B. 注册后免费下载** | 多数政府采购项目（公告写明"网上注册登记方式免费获取"） | 注册供应商账号（免费，需营业执照/法人信息）后登录下载 | CCGP 广西项目公告原文"本项目采用网上注册登记方式免费获取"（江苏）；招标文件售价 0 元字段常见 | ⭐⭐ 注册 1 个账号即可批量下载，主流通道 |
| **C. 付费/CA/第三方平台** | 工程建设类、央企项目、部分省份 | 需 CA 证书（企业数字证书，年费数百至数千元）或去第三方交易平台（如广西交投宏冠）注册；部分项目招标文件**有偿发售**（公告含"招标文件售价"字段） | CCGP 广西项目详情页"获取招标文件的地点：广西交投宏冠电子招标投标交易平台" | ⭐ 成本高，个人项目绕行 |

### 3.2 给项目的落地策略

1. **RAG 项目语料分层**：
   - L1 语料（必得）：招标公告 + 中标公告 + 更正公告全文 —— CCGP/GGZY 全量公开，无门槛，**足够撑起"招标公告知识问答"**；
   - L2 语料（主攻）：招标文件全文 —— 主攻 **A 类省份（江苏等）附件直链** + **B 类注册免费下载**，注册 1-2 个省的供应商账号即可积累数百份真实招标文件；
   - L3 语料（可选）：中标结果 + 评分数据 —— CCGP 中标公告字段齐全。
2. **智能投标助手项目的废标条款/资质提取**：依赖招标文件全文（L2），建议以 A/B 类省份为主采样；简历 demo 用 20-50 份即可说明问题。

## 4. 关键问题专项：中标公告字段与历史回填

### 4.1 中标公告/成交公告字段（CCGP 实测栏目 + 公开样例）

| 字段 | 说明 |
|---|---|
| 项目名称/项目编号 | 与招标公告对应 |
| 中标（成交）供应商 | 名称（+地址） |
| **中标（成交）金额** | 精确金额，字段规范化 |
| 主要标的信息 | 货物/服务/工程名称、规格、数量、单价 |
| 评审专家名单 | 政府采购中标公告标准字段 |
| 代理机构/公告日期 | 完整元信息 |

→ **结论：中标金额、中标人、评分（评审专家名单+综合评分法项目）均可从公开公告获得**，可支撑"中标结果分析""竞争对手监测"类简历卖点。

### 4.2 历史数据回填能力

| 渠道 | 回填能力 | 方式 |
|---|---|---|
| CCGP | **强**：详情页按 `栏目/YYYYMM/` 归档，可回查多年（实测 202608 目录正常，旧年份目录结构相同） | 列表页 JS 分页（需逆向翻页接口）+ 检索系统（强反爬需控频） |
| GGZY | 中：`/history/dealList.html` 历史库入口存在（JS 渲染），可回查近年 | 逆向 AJAX 接口[待核验参数] |
| CEBP | 中：公告归档可查 | 受 robots 限制，不建议程序化回填 |
| 第三方平台 | 强：会员制历史库（最省事，付费） | 官网检索/API |

→ **结论：能回填，但批量历史回填需要逆向 JS 接口（GGZY）或控频对抗（CCGP 检索）**；MV P 阶段建议从"当前存量"起步（列表页第 1-N 页即可拿到近期全量），历史深度按需扩展。

## 5. 商用/二次分发合规边界

### 5.1 法律框架（事实陈述，非法律意见）

- 招标公告/中标公告属于**政府主动公开信息**（《政府采购法》第 11 条、《招标投标法》、《政府信息公开条例》要求公开），公开信息本身可供社会公众查阅使用。
- 个人/学术使用（学习、研究、简历项目演示）：**低风险**。主流实践：低频爬取 + 注明来源 + 不转卖原始数据。
- **商业化再分发（转售数据流、做公开数据集售卖）**：灰色地带，需逐平台核对服务条款，涉及《数据安全法》"合法、正当"原则；**不建议**。
- 个人信息注意：公告含联系人姓名/电话（《个人信息保护法》视角），处理时避免收集无关个人信息、不外泄。

### 5.2 各平台 robots/条款实测

| 平台 | robots.txt | 程序化抓取合规评估 |
|---|---|---|
| CCGP | 无（403 响应，未公开 robots 内容） | 无 robots 禁令；有反爬（UA 检测+检索限流）→ 控频合规风险低 |
| GGZY | 无（404） | 无 robots 禁令；接口需逆向 → 低频可控 |
| CEBP | **`Disallow: /`（全部禁止）** | **明文禁止爬取** → 项目规避程序化抓取，仅人工浏览/参考数据规范 |
| PLAP | 无（404） | 军队数据敏感 → 不建议纳入爬取范围 |
| 省级平台 | 不一[待核验] | 江苏附件直链可下载（公开附件），建议注明来源 |

### 5.3 个人开发者主流做法（简历项目语境）

1. 用 CCGP/GGZY 公告数据做 demo（免登录、无 robots 禁令、公开属性强）；
2. 自建爬虫：低频（秒级间隔）、浏览器 UA、失败退避、尊重反爬信号（遇到拦截即停）；
3. 招标文件全文：走官方注册通道（供应商账号）而非绕开付费墙；
4. 展示合规：项目 README 注明"数据来源：中国政府采购网/全国公共资源交易平台，仅用于学习研究"；
5. 不做：公开转卖数据、爬取 CEBP（robots 禁止）、用军队采购数据做演示。

## 6. 推荐方案（主选 + 备用 + 理由）

### 6.1 主选：CCGP + GGZY 双主源

| 维度 | CCGP（政府采购） | GGZY（工程建设） |
|---|---|---|
| 覆盖 | 政府采购全量（中央+31省） | 跨省公共资源交易（含工程） |
| 门槛 | 公告免登录；文件 A/B 类可拿全文 | 公告免登录 |
| 格式 | HTML 结构化表格 + 附件直链 | HTML 正文页静态可抓 |
| 历史 | 按年月归档，回填友好 | 有历史库入口 |
| 反爬 | 检索强反爬，列表/详情静态可抓 | 列表 JS 渲染需逆向 |
| 综合 | **公告+中标数据第一来源** | **工程类+正文完整性补充** |

理由：两者合计覆盖"招标公告+中标公告+更正公告"全类型、免登录、无 robots 禁令、结构化程度高，是**合规与可得性的最优交集**。

### 6.2 备用/补充

1. **江苏省级平台（苏采云体系）**——招标文件全文附件直链实测可得，RAG 全文语料主补充；
2. **CEBP**——仅用于**人工检索**与《招标公告和公示数据接口规范》参考（robots 禁爬，不作为爬取源）；
3. **第三方聚合（剑鱼/千里马）**——项目上线阶段如需"检索体验+历史全量"可考虑付费会员/API（成本数百至数千元/年[待核验报价]）。

### 6.3 不建议用于本项目

- 军队采购网（敏感）；央企 CA 平台（成本高，个人无 CA）；招标代理官网（碎片化，效率低）。

## 7. 风险点

| 风险 | 等级 | 说明与缓解 |
|---|---|---|
| CCGP 检索系统强反爬 | 高（技术） | 已实测触发"频繁访问"拦截；缓解：用栏目列表页代替检索页、控频、随机延时 |
| CEBP robots 禁爬 | 高（合规） | 明文 `Disallow: /`；缓解：不爬，只人工用 |
| 列表页 JS 渲染（CCGP/GGZY） | 中（技术） | 需逆向分页接口；缓解：详情页静态直抓 + 列表接口逆向（工作量 1-2 天） |
| 各省平台碎片化 | 中 | 附件格式/接口不一；缓解：聚焦 2-3 个重点省份 |
| 公告中个人信息 | 中（合规） | 联系人电话等；缓解：入库时脱敏，仅存必要字段 |
| 招标文件全文可得性不足 | 中（项目成败） | 缓解：A/B 类通道已实测可行；C 类绕行 |
| 军队数据 | 低 | 不使用即可 |
